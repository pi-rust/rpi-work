# 澄蓝 · Clean SaaS

[可导入主题 JSON](clear-blue-saas.json) · 使用现有 Theme Design v2，不修改产品代码、CSS、组件结构或默认主题，不引入依赖和远程字体。

## 使用

1. 在支持 Theme Design v2 的 Work UI 中进入 **设置 → 界面与显示 → 外观与主题**。
2. 点击「导入主题」，选择 `clear-blue-saas.json`，预览后点击「保存」。默认浅色、标准密度，另提供配套深色配色。
3. 不满意时在保存前点击「取消」；保存后可重新选择原主题。导入只影响本设备外观，不修改模型、工具、会话或节点配置。

同一 ID 的不同内容不能覆盖导入。自行修改时请同步更换 `theme.id`，例如 `clear-blue-saas-v2`。

## 设计取舍

| 项目 | 配置 | 与原规范的关系 |
| --- | --- | --- |
| 页面 / 表面 | `#F4F6F8` / `#FFFFFF` | 冷灰画布与纯白侧栏、面板、卡片 |
| 强调 / 选中背景 | `#2563EB` / `#EFF6FF` | 保留科技蓝与浅蓝 |
| 文字 / 辅助文字 | `#111827` / `#5B6472` | 现有 palette 只有两个文字层级，不能分别指定标题、正文、辅助三色 |
| 边线 / 代码背景 | `#E5E7EB` / `#F3F4F6` | 浅灰分隔，保留代码区层次 |
| 字体 | `humanist`，代码 `code` | 本机 Inter 优先；不存在时回退 Segoe UI / Microsoft YaHei，不下载字体 |
| 排版 | 正文 / 导航 14px，辅助 12px，标题 16px / 500 | 长篇对话独立使用 16px、1.75 行高；代码保持等宽 13px |
| 圆角 | xs–xl：4 / 6 / 8 / 12 / 16px | 对应已有语义圆角，不覆盖固定圆角的组件 |
| 间距 | 标准密度，倍率 1.0 | 保留已有 16 / 24px 等语义间距，不通过整体放大使所有间距膨胀 |
| 控件 / 触控目标 | 40px / 44px | 控件视觉轻巧，沿用宿主移动安全规则 |
| 阴影 / 动效 | `subtle`；150 / 200 / 100ms | 使用宿主轻阴影预设，尊重系统减少动态效果设置 |

原规范的 `#9CA3AF` 在白底上的对比度不足 4.5:1，不适合作为 12px 说明文字；改用更深的 `#5B6472`，并同时满足冷灰底上的对比要求。深色模式使用更亮的蓝色 `#93C5FD`，不直接沿用浅色主按钮蓝。

## 不侵入代码的边界

这是**现有工作台的视觉主题**，不是整页重做或新仪表盘模板。只在组件已经消费主题 token 的位置生效。

- 不改变侧栏 / Header / 主内容布局，不强制所有内容左对齐或所有卡片采用 20–24px 内边距。
- 不新增 32–36px 数据大字角色；现有主题没有独立的数据指标字号字段，不能放大全局标题来冒充指标字号。
- 不把每个卡片或按钮变成无边框；主题边框最小为 1px，保留焦点、错误和选中反馈。
- 不注入自定义双层 box-shadow。`subtle` 是宿主预设，组件固定阴影可能仍保留，并非与规范中的 CSS 示例逐像素一致。
- 不修改成功 / 警告 / 错误等业务语义色；`#F59E0B` 标签不能在当前主题中独立配置。
- 不改变图表平滑曲线、渐变填充、虚线网格、图标库、图标描边或胶囊结构；这些由组件负责。
- 不引入 Tailwind、Ant Design、Element Plus 或额外字体请求；该主题直接适配现有 Rust / Dioxus 主题系统。

格式、范围和可访问性约束见 [Theme Design v2](../../docs/guides/theme-design.md)。
