# RPI Work 桌面工作台原型

直接打开 [index.html](index.html) 即可离线试用。首页是一段已有代码改动的双轮对话，桌面默认在右侧显示项目浏览器。切换会话、修改源码草稿和设置都在当前浏览器内完成。

参考图来源、哈希、截图条件与本轮消息层次差异见 [桌面视觉基准](VISUAL-BASELINE.md)；官方宣传图并非同条件完整应用截图，不作为整窗像素级一致性的证明。

## 可以直接试的流程

- **项目与会话**　「置顶」和「最近」都可折叠。打开项目菜单可以置顶整个文件夹，聊天会跟随项目移动。会话菜单支持单独置顶、重命名、分叉、交接或归档。顶栏箭头沿本次访问过的会话前进、后退。项目栏可搜索会话，或筛选执行中、待审批状态。归档会话可从设置恢复。
- **输入与目标**　在输入框键入 `/` 搜索命令，使用 `/plan` 切换计划、`/status` 查看上下文、`/new` 新建聊天，有改动时可选 `/review`。输入 `@` 可选择示例文件或已打开目录中的文件。按 ↑/↓ 选择，Enter 或 Tab 确认。通过 `/goal` 或左侧目标按钮为当前聊天设定目标，输入框上方可以编辑、暂停、继续或移除。建立目标会启动或排队一次演示轮次，暂停会停止该目标正在运行的轮次并移除它的排队项。
- **运行与审批**　在「设置 → 常规 → 下一轮演示」选择正常、命令审批或工具失败。发送消息后可看工具记录、引导本轮、排队、停止或重试。审批可允许一次、允许本会话或拒绝。计划生成后可点「开始实施」。新聊天可选择本地或 Worktree 及起始分支。
- **右侧浏览器**　用标签栏的加号新建浏览器标签，每个标签独立维护历史。地址栏可以打开实际运行的本地开发服务器及允许嵌入的 HTTP(S) 网页。`rpi://project/` 为离线项目示例。示例页的「批注」让你选择页面元素并把反馈附到下一条消息。点击预览中的文件会切换到源码。拖动分隔线调整宽度，双击恢复默认，也可切换完整视图。新对话会自动收起空的「变更」面板，回到有变更的会话时恢复；手动开关或选择标签后尊重用户操作。已打开的浏览器、源码面板不因新建对话而自动关闭。
- **文件与变更**　「文件」含文件树、标签、行号与高亮，支持编辑、保存和取消。「打开文件夹」可读取实际目录，在树中查看 1 MiB 以内的 UTF-8 源码。导入文件的草稿只在当前页面内存中保留，刷新后需重新选择文件夹。示例文件草稿按项目及路径持久保存。「变更」中可切换文件、复制差异、标记暂存、在差异行添加反馈，并在当前或独立审阅会话中查看示例发现。
- **设置与工具**　设置搜索可直接定位控件，支持系统主题、字号、阅读密度、行号、模型、推理强度、通知和后续消息处理。集成分类包含插件、MCP 服务器和技能。终端可试 `pwd`、`ls`、`git status`、`npm test` 或已配置的测试命令。计划任务支持创建、编辑、暂停、删除及手动「运行演示」，运行记录可跳转到对应会话。

- **消息阅读**　在「设置 → 外观 → 消息布局」切换「阅读 / 经典」：阅读布局保留靠右气泡，经典布局将用户消息与回答放在同宽阅读列中。偏好刷新后保留，可独立搭配主题、字号和密度；切换不重建消息，不清空草稿或工具展开状态，并尽量保持当前阅读位置。同一页面内切换会话、使用前进后退或暂时打开资源页，会记住各会话的阅读位置与工具展开状态；上翻阅读时不追随后台输出，原本在底部则继续跟随。阅读位置和展开状态不跨刷新保存。

## 快捷键

下表的修饰键在 macOS 为 ⌘，在其他系统为 Ctrl。普通浏览器可能优先处理自身快捷键，相同操作均可从界面进入。

| 操作 | 快捷键 |
| --- | --- |
| 搜索会话与操作 | 修饰键 + K |
| 新对话 | 修饰键 + N |
| 会话侧栏 | 修饰键 + B |
| 右侧面板 | 修饰键 + Shift + B |
| 底部终端 | 修饰键 + J |
| 设置 | 修饰键 + 逗号 |
| 发送 / 换行 | Enter / Shift + Enter |

## 数据与执行范围

会话、目标、草稿、队列、暂存标记、偏好与计划任务保存在当前浏览器的本地存储。刷新会中断正在运行或待审批的演示轮次，保留的队列可以手动继续。浏览器标签历史、会话前进后退和终端历史限于本次打开页面。

实际网页在受限 iframe 中展示。对于限制嵌入的网站，使用「在新窗口打开」。附件记录文件名，`@` 引用记录相对路径。终端输出、模型回复、审阅结论和连接状态由本地逻辑生成。真实模型推理、持续执行并验收目标、写入磁盘、Git 与 Worktree 操作、SSH、MCP 连接和按时调度均需接入运行服务。工作台可对接仓库现有节点客户端。开源 Codex 提供运行时和协议参考。[RPI 节点客户端](../reui-codex/src/lib/node.ts) · [openai/codex](https://github.com/openai/codex)

## 本地验证

在工作树根目录启动静态服务后，可直接进入对应视图。[工作台](http://127.0.0.1:4193/) · [代码](http://127.0.0.1:4193/?panel=code) · [设置](http://127.0.0.1:4193/?view=settings) · [历史加载](http://127.0.0.1:4193/?history=loading) · [历史失败与重试](http://127.0.0.1:4193/?history=error)

历史加载入口是显式的本地展示夹具，不会请求节点或模型：`history=loading` 在 800ms 后展示已有记录；`history=error` 在 800ms 后展示失败，「重试加载」再经过 800ms 恢复。加载中及失败时保留可编辑草稿与附件，但禁发；切换会话或进入新对话会取消旧展示结果，已加载的会话在本次页面内直接返回。默认入口仍是即时切换，不人为添加等待；`view=new` 仍直接打开空态。刷新后保留草稿和附件文件名，不保留加载缓存。

```sh
python3 -m http.server 4193 --bind 127.0.0.1 --directory design/reui-message-layout
```

用仓库 `tools/` 中的 Playwright 和已安装的 Chromium 运行浏览器回归。设置环境变量 `RPI_WORKBENCH_SHOTS` 可将截图输出到指定目录。

当前回归包含 16 组流程。正文排版检查覆盖已有/新回答在16/18px、舒适/紧凑、明暗和阅读/经典布局下的一致行距，字号/密度变化后的可见块锚点与底部跟随，代码/日志独立字号、草稿/DOM/展开状态保留，以及长正文换行和代码局部横向滚动。预览像素检查从原始整窗 PNG 统计标题和主体的文字像素，覆盖浅/深/系统主题、弹窗往返与普通/可控时钟；同时确认主题切换不重载 iframe、不丢未保存表单和选区、不放宽沙箱。先前的「预览主体空白」目检记录已被原始截图与裁切证据推翻，详见视觉基准。消息层次检查覆盖最终正文与阅读列对齐、完成步骤默认折叠、原生摘要键盘开关、明暗/阅读/经典布局、完成和后台完成时保留已展开工具，以及「开始实施」和失败重试入口始终可见。会话阅读恢复检查覆盖各会话的滚动锚点、工具展开与收起、前进后退、资源页往返、后台流式更新、原本在底部时继续跟随，以及历史加载场景和字号/布局变化后的返回。阅读布局检查覆盖两种布局的实际几何与样式、刷新持久化、无效偏好回退、草稿和工具展开状态、滚动锚点、1440/1280/1024px 桌面宽度，以及新对话的空变更收起、返回恢复、鼠标与键盘手动覆盖和浏览器/源码保留。历史展示检查覆盖加载和失败时禁发、重试恢复、草稿与附件刷新保留、快速切换时的过期结果取消，以及空态发送首条消息。输入菜单检查覆盖 Home/End 与 Shift 选区变化、过期引用范围保护、上下键选择、正文前缀保留，以及中文组合事件与菜单/发送的隔离；事件回归不等于所有原生输入法都已实机验证。截图输出包含相同视口与字号下的两种布局、深色布局、三种新对话面板状态及历史加载/失败/恢复。这些是原型交互与布局验证，不代表已经实现桌面像素级 1:1 对齐。

node design/reui-message-layout/verify.cjs
