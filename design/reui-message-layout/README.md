# RPI Work 桌面工作台原型

直接打开 [index.html](index.html) 即可离线试用。首页是一段已有代码改动的双轮对话，桌面默认在右侧显示项目浏览器。切换会话、修改源码草稿和设置都在当前浏览器内完成。

参考图来源、哈希、截图条件与本轮消息层次差异见 [桌面视觉基准](VISUAL-BASELINE.md)；官方宣传图并非同条件完整应用截图，不作为整窗像素级一致性的证明。当前整窗场景结论与迁移前待确认事项见 [设计复核记录](DESIGN-REVIEW.md)。

## 可以直接试的流程

- **rpi 启动引导**　启动时先显示演示检测状态：[已检测到可用 rpi](screenshots/rpi-startup-ready.png) 则直接进入工作台，不弹窗；未检测到才自动弹出配置选择，让用户选择下载安装或手动指定已有 rpi。弹窗只保留一个「rpi 路径」框，下载和手动定位共用。没有 rpi 时点下载便直接显示[百分比进度](screenshots/rpi-setup-downloading.png)，随后自动演示校验，成功后回填同一路径框并保存，无须先选择安装目录或再次点验证；失败不回填、不保存成功配置。已有 rpi 可选择 `rpi` / `rpi.exe` 程序、已有目录，或手动填写位置。示例回填路径 `~/.local/bin/rpi` 不代表本机已安装；演示配置刷新后保留且不再弹窗。关闭引导会取消进行中的演示任务，保留草稿、选区及原焦点，本次启动不重复弹出；之后仍可通过侧栏重新打开。所有检测、下载和执行都没有真实接入，只有文件/目录选择器是真实浏览器交互；官方发布页需要用户主动打开。[缺失时自动引导](screenshots/rpi-startup-guide.png) · [手动定位](screenshots/rpi-setup-manual.png) · [演示配置完成](screenshots/rpi-setup-ready.png)
- **添加项目**　独立「项目」分组的标题旁放置「＋」图标，悬停提示「添加项目」。默认添加到「此电脑」，也可选择所属节点。本机支持「选择文件夹」，名称自动填入；远程节点须手动填写其路径，禁用本机选择器，原型不访问远程文件系统。也可自行编辑名称或手动填写路径。本机目录选择优先使用原生目录选择器，不支持时使用浏览器文件夹输入；取消、拒绝或过期结果不覆盖原填写。浏览器只记录目录名，不返回绝对路径，也不读取文件内容；绝对路径与真实目录接入留给桌面端。添加后进入新项目对话，只展开项目分组和目标节点，不改变最近会话的折叠或筛选状态。空白名称/路径和重名会提示；取消或 Esc 不添加项目、不清空原对话草稿。项目元数据仅保存在浏览器，不创建目录。[入口截图](screenshots/add-project-entry.png) · [添加弹窗](screenshots/add-project-dialog.png) · [添加完成](screenshots/project-added.png)
- **工作协同**　在「设置 → 工作协同」（原「连接」）查看[当前节点与访问开关](screenshots/collaboration-current.png)、[远程节点](screenshots/collaboration-remote.png)、[附近节点和连接／访问记录](screenshots/collaboration-discovery.png)。沿用旧版功能结构，使用当前设置页的字体、单色图标、行分隔和明暗 token。本机固定保留，连接后可切换或模拟断开；远程权限只能在拥有节点的电脑上管理。远程协作、Web 访问与局域网发现独立、默认关闭，演示偏好刷新保留。地址连接先[预览再确认](screenshots/collaboration-connect.png)，不自动切换当前节点；新增节点同步到项目所属节点选项，拒绝含凭据、查询参数或片段的地址。[一次性授权](screenshots/collaboration-authorization.png)展示120秒过期与重新生成，二维码为不可扫码的占位，不签发票据；关闭弹窗不宣称真实授权已撤销。[手机视图](screenshots/collaboration-mobile.png)提供扫码演示入口但不调用摄像头、不读相册，隐藏桌面入站设备面板。可展开「演示状态」检查连接失败、未发现节点、入口未就绪及示例访问记录。整个流程不扫描网络、不连接节点、不收集密码、不改变真实服务，也不搬动当前对话、草稿或项目。
- **项目显示与节点**　在「设置 → 常规 → 工作区 → 项目列表显示」选择[按节点分组](screenshots/projects-by-node.png)或[平铺](screenshots/projects-flat.png)，默认按节点分组；[设置截图](screenshots/project-node-settings.png)。节点显示项目数量、支持独立折叠，切换模式及刷新后保留偏好。平铺时每个项目旁仅用本机 / 远程小图标表示节点，悬停显示节点名称；项目按钮保留可访问的节点描述。分组标题仍显示节点名，避免多个节点混淆；切换只重建项目列表，不改变对话、草稿、选区、阅读位置或右侧预览。旧项目缺少节点信息时归到此电脑，未知节点身份保留为未知，不冒认本机。示例「开发主机」沿用连接页的演示节点；[远程添加示例](screenshots/add-remote-project.png)只保存节点和路径元数据，不代表真实连接。
- **项目与会话**　「项目」「置顶」「最近」分别折叠、独立保存偏好。项目列表只显示项目；点击项目进入该项目的新对话，项目菜单支持置顶项目：分组时仅在所属节点内排序，平铺时在总列表排序，不会移动其会话。「置顶」只显示单独置顶的会话；「最近」直接平铺其他会话，不再按项目嵌套，悬停会话可查看所属项目和完整标题。会话菜单支持置顶、重命名、分叉、交接或归档。顶栏箭头沿本次访问过的会话前进、后退。搜索和执行中/待审批筛选仅影响会话，项目仍可独立访问。旧版最近分组折叠偏好会迁移到新版最近会话，不误折叠项目列表。归档会话可从设置恢复。
- **输入与目标**　在输入框键入 `/` 搜索命令，使用 `/plan` 切换计划、`/status` 查看上下文、`/new` 新建聊天，有改动时可选 `/review`。输入 `@` 可选择示例文件或已打开目录中的文件。按 ↑/↓ 选择，Enter 或 Tab 确认。通过 `/goal` 或左侧目标按钮为当前聊天设定目标，输入框上方可以编辑、暂停、继续或移除。建立目标会启动或排队一次演示轮次，暂停会停止该目标正在运行的轮次并移除它的排队项。
- **运行与审批**　在「设置 → 常规 → 下一轮演示」选择正常、命令审批或工具失败。发送消息后可看工具记录、引导本轮、排队、停止或重试。审批可允许一次、允许本会话或拒绝。计划生成后可点「开始实施」。新聊天可选择本地或 Worktree 及起始分支。
- **右侧浏览器**　用标签栏的加号新建浏览器标签，每个标签独立维护历史。地址栏可以打开实际运行的本地开发服务器及允许嵌入的 HTTP(S) 网页。`rpi://project/` 为离线项目示例。示例页的「批注」让你选择页面元素并把反馈附到下一条消息。点击预览中的文件会切换到源码。拖动分隔线调整宽度，双击恢复默认，也可切换完整视图。新对话会自动收起空的「变更」面板，回到有变更的会话时恢复；手动开关或选择标签后尊重用户操作。已打开的浏览器、源码面板不因新建对话而自动关闭。
- **文件与变更**　「文件」含文件树、标签、行号与高亮，支持编辑、保存和取消。「打开文件夹」可读取实际目录，在树中查看 1 MiB 以内的 UTF-8 源码。导入文件的草稿只在当前页面内存中保留，刷新后需重新选择文件夹。示例文件草稿按项目及路径持久保存。「变更」中可切换文件、复制差异、标记暂存、在差异行添加反馈，并在当前或独立审阅会话中查看示例发现。
- **设置与工具**　设置搜索可直接定位控件，支持系统主题、字号、阅读密度、行号、模型、推理强度、通知和后续消息处理。集成分类包含插件、MCP 服务器和技能。终端可试 `pwd`、`ls`、`git status`、`npm test` 或已配置的测试命令。计划任务支持创建、编辑、暂停、删除及手动「运行演示」，运行记录可跳转到对应会话。

- **消息阅读**　在「设置 → 外观 → 消息布局」切换「阅读 / 经典」：阅读布局保留靠右气泡，经典布局将用户消息与回答放在同宽阅读列中。偏好刷新后保留，可独立搭配主题、字号和密度；切换不重建消息，不清空草稿或工具展开状态，并尽量保持当前阅读位置。同一页面内切换会话、使用前进后退或暂时打开资源页，会记住各会话的阅读位置与工具展开状态；上翻阅读时不追随后台输出，原本在底部则继续跟随。阅读位置和展开状态不跨刷新保存。

## 数据与执行范围

会话、目标、草稿、队列、暂存标记、偏好与计划任务保存在当前浏览器的本地存储。刷新会中断正在运行或待审批的演示轮次，保留的队列可以手动继续。浏览器标签历史、会话前进后退和终端历史限于本次打开页面。

实际网页在受限 iframe 中展示。对于限制嵌入的网站，使用「在新窗口打开」。附件记录文件名，`@` 引用记录相对路径。终端输出、模型回复、审阅结论和连接状态由本地逻辑生成。真实模型推理、持续执行并验收目标、写入磁盘、Git 与 Worktree 操作、SSH、MCP 连接和按时调度均需接入运行服务。工作台可对接仓库现有节点客户端。开源 Codex 提供运行时和协议参考。[RPI 节点客户端](../reui-codex/src/lib/node.ts) · [openai/codex](https://github.com/openai/codex)

## 本地验证

在工作树根目录启动静态服务后，可直接进入对应视图。[工作台](http://127.0.0.1:4193/) · [代码](http://127.0.0.1:4193/?panel=code) · [设置](http://127.0.0.1:4193/?view=settings) · [历史加载](http://127.0.0.1:4193/?history=loading) · [历史失败与重试](http://127.0.0.1:4193/?history=error)

历史加载入口是显式的本地展示夹具，不会请求节点或模型：`history=loading` 在 800ms 后展示已有记录；`history=error` 在 800ms 后展示失败，「重试加载」再经过 800ms 恢复。加载中及失败时保留可编辑草稿与附件，但禁发；切换会话或进入新对话会取消旧展示结果，已加载的会话在本次页面内直接返回。默认入口仍是即时切换，不人为添加等待；`view=new` 仍直接打开空态。刷新后保留草稿和附件文件名，不保留加载缓存。

```sh
python3 -m http.server 4193 --bind 127.0.0.1 --directory design/reui-message-layout
```
