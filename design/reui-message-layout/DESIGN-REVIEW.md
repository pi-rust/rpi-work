## 评审反馈补充：添加项目

用户进一步明确：「最近」应该是会话列表，项目应独立成组，并在项目标题旁放添加图标。此前只移动了入口，尚未分离项目和会话的数据层级；本次将侧栏改为独立「项目」「置顶会话」「最近会话」，不改变正文或审阅区布局：

- 「项目」标题旁放置「＋」图标，保留「添加项目」可访问名称和悬停提示。项目行不再嵌套会话，点击项目进入该项目的新对话；弹窗支持取消、Esc、空白及重名提示。
- 「最近」平铺非置顶会话，「置顶」只放单独置顶的会话；项目置顶仅改变项目列表排序，不搬动或重复会话。会话悬停提示所属项目及完整标题。
- 打开弹窗时聚焦名称；取消不清空原对话草稿、选区或阅读位置，重新打开清除旧错误。
- 添加后仅展开项目分组，保留最近会话的折叠和筛选状态；项目访问及置顶也不清空会话筛选。三个分组独立保存折叠偏好，旧版最近分组偏好迁移到新版最近会话，不误折叠项目列表。
- 项目元数据仅保存在当前浏览器中，不创建目录、不读取文件内容、不接入真实节点；设计确认及 renderer 迁移边界不变。

新增回归已随完整21组流程通过。另在运行中的4193预览上以1440×940、DPR1抓取[入口](screenshots/add-project-entry.png)、[目录选择后的弹窗](screenshots/add-project-dialog.png)和[添加完成](screenshots/project-added.png)，检查浅/深色错误状态与刷新保存，无页面错误。截图中的 `notes-app` 来自临时测试目录，仅记录目录名，未读取文件内容。

## 评审反馈补充：目录选择与 rpi 启动引导

用户确认先补原型：添加项目可以选择文件夹，启动时体现 rpi 缺失后的下载安装引导，或手动选择已有程序 / 安装目录。

- 添加项目优先使用原生目录选择器，回退到浏览器文件夹输入；自动填写名称但保留自定义名称。取消、拒绝或返回过晚的选择不覆盖当前表单。目录名不是绝对路径，界面明确说明；不读取所选文件内容。
- 启动分支按最新确认调整：[已检测到可用 rpi](screenshots/rpi-startup-ready.png) 时静默进入工作台，不弹窗；未检测到才自动弹出[配置选择](screenshots/rpi-startup-guide.png)，让用户选择下载安装或手动指定已有 rpi。不静默下载安装，关闭后本次启动不再自动弹出，侧栏保留重新打开入口。选择目标目录后可演示下载和验证；下载完成与验证通过分开，失败可重试。
- 可[手动定位](screenshots/rpi-setup-manual.png) `rpi` / `rpi.exe` 或已有安装目录，也可填写位置。选择程序仅做文件名检查，不能证明其可执行性、版本或安全性。
- 检测、下载、校验和及版本验证都没有真实接入；只有选择器是真实浏览器交互，成功仅保存[演示配置](screenshots/rpi-setup-ready.png)。关闭引导取消未完成的演示任务，保留草稿及选区。官方发布页须用户主动打开，本原型不运行安装脚本。
- 新增专门回归覆盖以上成功、失败、取消、过期及刷新场景；新增断言验证检测成功不弹窗、缺失自动弹出、关闭不反复弹出、自动引导结束后草稿选区及焦点恢复，整体21组通过。其他工作台回归显式使用启动成功夹具，组合视图查询参数时不会丢失启动状态。未读取文件内容、未联网下载、未执行程序。自动化目录句柄使用桩，文件夹输入使用临时目录，不等于原生桌面安装与系统选择器的完整实机验收。

## 当前结论

- 首轮整窗复核没有发现足以支撑再次改变布局的新增、可复现证据；后续仅按明确反馈补齐侧栏、目录选择及 rpi 设置引导，不随意改正文/审阅列宽、间距或扩建演示后端能力。
- 当前 HTML 已覆盖执行/完成/失败、历史恢复、阅读状态、代码/diff 局部溢出、复制反馈及焦点可见性；这不是生产协议或完整产品实现。
- 最新完整21组回归、语法、结构和差异检查通过；焦点 PNG 检查为16种消息代码与8种源码只读/编辑组合，对比度审计为列明范围的92个颜色样本。
- 一次整套验证发生过超时，后续独立检查和完整重跑通过；不把成功重跑说成所有环境都稳定，也未为此添加预览修复。
- 原生 ArrowRight 探针在新窗口也会偶发超时，默认不作为稳定门槛；可选诊断及其他验证边界均见[视觉基准](VISUAL-BASELINE.md)。不宣称原生键滚、IME实机或全应用无障碍已经完整验收。

## 需要设计确认的边界

1. 是否接受当前桌面方向：左侧会话、中间阅读、右侧默认项目浏览器，以及当前阅读布局和正文层次。
2. 是否接受完成过程默认收起、最终回答独立展示，并保留工具展开、实施与重试入口的交互方向。
3. 若要求严格 Codex 1:1，需要目标应用版本、同内容/阶段、主题、字体、缩放/DPR、面板宽度和未裁切的同条件整窗截图。现有宣传图不能完成这项验收。

设计确认后再单独讨论真实 renderer 迁移。迁移必须复用 `work-client`、`RunProjection`、`work-viewmodel`，不把 HTML 演示状态机当运行协议；本记录不授予迁移、合并或推送许可。
