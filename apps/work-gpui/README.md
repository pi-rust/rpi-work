# RPI Work · GPUI 工作台

当前唯一维护的 UI 入口。布局参照 [`design/reui-message-layout/`](../../design/reui-message-layout/)，由 GPUI 原生渲染。

在仓库根目录运行：

```bash
# 原生布局样例，窗口标注「示例 · 未连接」
task desktop

# 认证后连接已运行的 Work 节点
# 如需登录，在环境或 .env.local 中设置 RPI_WORK_PASSWORD
task desktop -- --connect http://127.0.0.1:13031

# 无 Task 时可用 Cargo 直接启动
cargo run --manifest-path apps/work-gpui/Cargo.toml
```

项目和会话使用 `work-client`。选中的会话由共享 `SessionConnection` 持续接收消息、工具与运行结算，断线后恢复快照和订阅。节点声明发送能力且会话空闲时，按 Enter 发送纯文本，Shift+Enter 换行。草稿保存在当前窗口。已创建的会话各有草稿，新对话按项目分别保存。节点受理后等待运行结算。发送结果未知时，有回执引用可点「核对回执」查询，草稿保留且客户端不会重发。

输入区支持原生输入法、多行编辑、鼠标及键盘选区、系统剪贴板。输入法候选尚未确认时，Enter 交给输入法。

输入栏的模型和思考等级由当前会话声明的能力、运行状态和节点目录决定。同名模型按供应商区分。修改受理后读取节点当前值，存在可核对的受理结果或回执时可点「核对配置」，只读取状态。

运行期间可点击方形按钮请求停止。停止回执返还的后续消息追加到原会话草稿。支持队列的会话运行时，可用 Enter 或「提交」将文本排队或引导本轮，带附件的草稿可以在结算后发送。输入框上方显示节点确认的后续消息，可按能力移除条目。节点报告有待恢复运行时会显示「继续队列」。

节点发来的单选审批会显示在输入框上方，选项按节点提供的值提交，等待节点关闭审批。节点声明的多选和文本问题可通过「编辑回答」提交，文本输入复用原生输入法。停止或回复结果未知时，可以用节点返回的回执引用只读核对。

历史回答和流式回复通过共享 Markdown 视图显示标题、强调、清单、引用、表格和语法着色的代码块。代码块支持复制和独立滚动。通过共享校验的 HTTP(S) 链接可在系统浏览器打开，图片显示替代文字。

左栏项目列表旁的「＋」可将已连接节点上的现有目录添加为项目。可输入路径，也可浏览节点目录。添加后会读取项目列表核对登记结果。

左栏的「项目」「置顶」「最近」可独立折叠。项目默认按节点分组，分组标题显示项目数量，也可单独折叠。可在「设置 → 常规 → 工作区 → 项目列表显示」切换平铺。项目行的「⋯」可以置顶项目。置顶按节点和项目 ID 保存在本机，仅调整项目列表顺序。

点击项目可进入新对话页，选择项目并将任务建议添加到草稿。首次发送会创建会话并核对身份和发送能力。左栏的「新对话」也可以直接创建并读回会话。窗口顶栏的前进和后退按访问顺序恢复项目和会话，并跳过已归档会话。窄窗使用覆盖式导航和审阅抽屉，桌面可拖动右栏分隔线。

左栏标题旁的「筛选会话」可在「全部会话」「执行中」「待审批」之间切换，作用于置顶和最近两组。「执行中」也包括待审批。选择状态后会定期读取节点列表，保留当前对话、草稿和审阅页。旧节点缺少活动字段时显示状态未知。

顶栏标题旁的「⋯」提供重命名、置顶和归档。归档后可从左栏底部的「已归档会话」恢复，原有草稿仍保留。会话资料以节点读回为准。写入结果未确认时，可用「核对会话资料」只读重查。

支持分叉的空闲原生会话可通过「⋯ → 从历史分叉」将当前历史复制到同项目的新会话。支持历史定位时，已确认的回答还提供「从此处开始新对话」，新会话的历史截止于该回答。节点已确认目标 ID 后，可用「核对新会话」只读重查列表。写入回执丢失时，重新连接工作台可查看节点列表。

右栏的「文件」通过当前节点读取所选项目的目录和源码，支持分页、返回、刷新和复制原文。「变更」在同栏显示工作树文件列表和选中文件的差异。增删行数来自实际文本补丁，分别核对已暂存和未暂存范围后合计。二进制或未取得完整补丁的文件没有行数，只有所有文件均有行数时显示总计。可分别查看两种范围，并复制差异原文。文本差异的行末加号可添加批注。提交批注前会重新读取同一文件和暂存范围，核对补丁内容。核对成功的批注会出现在该行和当前会话草稿中，可随下一条消息发送。「运行审阅」核对工作树仍有改动后提交审阅请求。右栏可切换「当前会话」或「独立会话」。独立审阅在节点创建新会话，核对列表及发送能力后提交，并保留原会话草稿。

macOS 右栏的「＋」打开内嵌浏览器标签。输入 HTTP(S) 地址后可前进、后退、刷新、在系统浏览器打开，以及切换自适应和 390 点移动视口。标签切换和面板隐藏保留网页状态，每个标签使用非持久化 WebKit 数据存储。「批注」允许在网页主文档中选取元素，写入当前会话草稿并随下一条消息发送。批注位置记录网页地址、元素类型和简短可见文本。

输入栏「＋」打开系统文件选择器。支持有序内容块的会话可以随消息发送 PNG、JPEG 和 UTF-8 文本。所选文件先显示为可移除的草稿标签。受理后清理本次提交的附件，发送结果未知时保留附件以便核对。

`rpi-ask-user` 的多题调用逐题打开对话框。工作台按节点请求 ID 回复，每次回答后由节点推进到下一题。

左下角齿轮或 `⌘ ,`（其他平台为 `Ctrl ,`）打开「设置」。窄窗可从左侧导航打开全屏设置，再用「浏览分类」展开搜索。输入分类或控件名称可定位设置。Enter 跳到首个结果，↓ 将焦点移到结果列表，Escape 先清除查询，再关闭设置。

「外观」提供浅色、深色和跟随系统，可调整消息布局、字号、密度和代码行号。「常规」可隐藏输入栏下方的上下文入口，选择新会话的后续消息处理方式，并设置审阅结果进入当前或独立会话。偏好保存在本机，审阅方式和右栏中的选项同步。

「通知 → 任务完成提示」默认关闭。开启后，当前会话收到实时结算时，工作台底部会显示完成、失败或停止等结果，三秒后自动消退。开关保存在本机。

工作台内按 `⌘ N` 打开当前项目的新对话草稿，`⌘ B` 切换侧栏，`⌘ Shift B` 切换浏览器面板。其他平台使用 `Ctrl`。窄窗用 Escape 关闭抽屉。「键盘快捷键」同时列出消息输入和设置搜索的键位。

侧栏放大镜或 `⌘ K`（其他平台为 `Ctrl K`）打开「搜索与操作」。可按会话或项目名称查找当前节点中的项目与未归档会话，也可查找新对话、浏览器、代码工作区和设置。查询以 `>` 开头时只显示操作。Enter 打开首个结果，↓ 聚焦结果列表，Escape 返回原草稿。

点击输入栏下方的「上下文」，或在搜索中输入 `> 查看上下文`，即可查看当前会话的项目、执行节点、模型、推理强度、消息轮次、后续消息和已报告的上下文窗口用量。节点未报告会话执行权限时，弹窗会明确标明。

「已归档的聊天」显示会话及所属项目。Tab 聚焦「恢复」，Enter 或空格可激活。节点确认恢复后，会话重新进入导航列表，设置页和当前草稿保留。侧栏「已归档会话」恢复后直接打开该会话。

「设置 → 工作协同」显示当前节点地址和节点 ID。可以复制地址，也可以刷新附近节点。工作台使用共享客户端验证局域网发现的节点，并显示每个节点是否需要登录。可手动输入 HTTP(S) 地址，或从附近节点和最近连接打开。目标节点需要认证时，会提示输入该节点的密码。连接成功后，目标节点在独立工作台窗口打开，原窗口保留当前会话与草稿。最近连接保存地址和节点 ID，每次打开重新认证。

macOS 工作台的「地址二维码」可分享由接收设备访问的 HTTP(S) 地址。工作台先通过无凭据请求核对目标地址的节点 ID，再生成与 RPI Work 扫码客户端兼容的二维码。二维码只携带节点地址，连接时按节点要求登录。共享管理和一次性授权需要节点所属电脑提供本机控制入口。

## 构建与平台

GPUI 0.2.2 与旧 Dioxus 的 `cocoa` 版本要求冲突，本应用使用独立 Cargo workspace。macOS 通过 `runtime_shaders` 在运行时编译着色器，可使用 Command Line Tools。Linux 和 Windows 的 GPUI 构建尚待验证。GPUI 0.2.2 的平台后端面向桌面。

```bash
cargo fmt --manifest-path apps/work-gpui/Cargo.toml -- --check
cargo test --manifest-path apps/work-gpui/Cargo.toml
cargo clippy --manifest-path apps/work-gpui/Cargo.toml --all-targets -- -D warnings
```
