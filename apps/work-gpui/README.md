# RPI Work · GPUI 工作台

当前唯一维护的 UI 入口。布局参照 [`design/reui-message-layout/`](../../design/reui-message-layout/)，由 GPUI 原生渲染。

在仓库根目录运行：

```bash
# 检测 rpi 并打开本机工作区
task desktop

# 打开原生布局样例
task desktop -- --sample

# 认证后连接已运行的 Work 节点
# 如需登录，在环境或 .env.local 中设置 RPI_WORK_PASSWORD
task desktop -- --connect http://127.0.0.1:13031

# 无 Task 时可用 Cargo 直接启动
cargo run --manifest-path apps/work-gpui/Cargo.toml
```

启动时先在本机检测已有 rpi。未找到可用版本时，配置窗口会提供「下载并安装 rpi」和「选择已有路径」。点选下载才会联网。下载期间可以点「取消下载」或按 Escape，停止后回到选择界面。选择已有路径时，可输入路径，或通过系统选择器选择可执行文件、安装目录，再点「验证 rpi」。也可直接连接远程节点，或用 `--connect` 指定节点。

正式桌面包在工作台就绪后及每 6 小时检查稳定版。从 GitHub 取得的清单通过 Ed25519 验签后，应用按当前平台和架构下载更新包，并验证 SHA-256。下载完成后可在「设置 → 常规 → 应用更新」点「重启并安装」。同一位置可以关闭自动检查和下载，或手动检查。macOS 需从已解压的 `RPI Work.app` 运行。当前安装目录需要可写。

项目和会话使用 `work-client`。选中的会话由共享 `SessionConnection` 持续接收消息、工具与运行结算，断线后恢复快照和订阅。节点声明发送能力且会话空闲时，按 Enter 发送纯文本，Shift+Enter 换行。节点受理后等待运行结算。发送结果未知时，有回执引用可点「核对回执」查询，草稿保留且客户端不会重发。

草稿正文会保存在本机设置目录下的 `gpui-drafts`，重新打开相同项目或会话即可恢复。已创建的会话和各项目的新对话分别保存。附件、文件引用和批注留在当前窗口。布局示例及未提供稳定身份的远程节点也使用窗口草稿。应用重开时，仍未确认发送或入队的草稿会提示先查看会话和后续消息。点击「允许再次发送」后，可手动发送。

输入区支持原生输入法、多行编辑、鼠标及键盘选区、系统剪贴板。输入法候选尚未确认时，Enter 交给输入法。

输入栏的模型和思考等级由当前会话声明的能力、运行状态和节点目录决定。同名模型按供应商区分。修改受理后读取节点当前值，存在可核对的受理结果或回执时可点「核对配置」，只读取状态。

运行期间可点击方形按钮请求停止。停止回执返还的后续消息追加到原会话草稿。支持队列的会话运行时，可用 Enter 或「提交」将文本排队或引导本轮，带附件的草稿可以在结算后发送。输入框上方显示节点确认的后续消息，可按能力移除条目。节点报告有待恢复运行时会显示「继续队列」。

节点发来的单选审批会显示在输入框上方，选项按节点提供的值提交，等待节点关闭审批。节点声明的多选和文本问题可通过「编辑回答」提交，文本输入复用原生输入法。停止或回复结果未知时，可以用节点返回的回执引用只读核对。

历史回答和流式回复通过共享 Markdown 视图显示标题、强调、清单、引用、表格和语法着色的代码块。代码块支持复制和独立滚动。通过共享校验的 HTTP(S) 链接可在系统浏览器打开，图片显示替代文字。

聊天记录的阅读位置和工具详情展开状态按节点、项目及会话保存在本机。重开会话时优先回到原先阅读的消息，消息缺少稳定标识或已不存在时按保存的滚动位置恢复。停在底部的会话重开时会显示最新消息。缺少稳定身份的远程节点在当前窗口内保留阅读状态。

左栏项目列表旁的「＋」可将已连接节点上的现有目录添加为项目。本机可以输入路径或用系统选择器选择文件夹，名称留空时会自动填入文件夹名。远程项目可输入路径或浏览该节点的目录。添加后会读取项目列表核对登记结果。

左栏的「项目」「置顶」「最近」可独立折叠。项目默认按节点分组，可在「设置 → 常规 → 工作区 → 项目列表显示」切换平铺。点击项目名或箭头展开会话，当前项目默认展开。每个项目先显示最近五条会话，并保留当前会话。点击「显示更多」查看其余会话。「置顶」和「最近」仍可用来快速打开会话。

右键项目或点击「⋯」可新建对话、重命名项目、置顶项目、复制路径、查看节点信息或归档项目。本机项目还可以在系统文件管理器中打开。项目归档只将它和所属会话从本设备的侧栏隐藏，可从侧栏底部的「已归档」恢复。

点击项目旁的「＋」进入新对话页。首次发送会创建会话并核对身份和发送能力。窗口顶栏的前进和后退按访问顺序恢复项目和会话，并跳过已归档会话。窄窗使用覆盖式导航和审阅抽屉，桌面可拖动右栏分隔线。

左栏标题旁的「筛选会话」可在「全部会话」「执行中」「待审批」之间切换，作用于项目下的会话和「置顶」「最近」快捷列表。「执行中」也包括待审批。选择状态后会定期读取节点列表，保留当前对话、草稿和审阅页。旧节点缺少活动字段时显示状态未知。

顶栏标题旁的「⋯」提供重命名、置顶和归档。归档后可从左栏底部的「已归档」恢复，原有草稿仍保留。会话资料以节点读回为准。写入结果未确认时，可用「核对会话资料」只读重查。

支持分叉的空闲原生会话可通过「⋯ → 从历史分叉」将当前历史复制到同项目的新会话。支持历史定位时，已确认的回答还提供「从此处开始新对话」，新会话的历史截止于该回答。节点已确认目标 ID 后，可用「核对新会话」只读重查列表。写入回执丢失时，重新连接工作台可查看节点列表。

右栏的「文件」通过当前节点读取所选项目的目录和源码。展开目录时按需加载，长目录可以继续加载，打开源码后仍可浏览目录。已打开的文件可在同项目的标签间切换，支持关闭标签、刷新文件树和复制源码。「变更」在同栏显示工作树文件列表和选中文件的差异。增删行数来自实际文本补丁，分别核对已暂存和未暂存范围后合计。二进制或未取得完整补丁的文件没有行数，只有所有文件均有行数时显示总计。可分别查看两种范围，并复制差异原文。桌面新对话会自动收起确认没有改动的「变更」面板，仍可从顶栏手动打开。长行横向滚动时，行号和用于添加批注的加号固定在两侧。提交批注前会重新读取同一文件和暂存范围，核对补丁内容。核对成功的批注会出现在该行和当前会话草稿中，可随下一条消息发送。「运行审阅」核对工作树仍有改动后提交审阅请求。右栏可切换「当前会话」或「独立会话」。独立审阅在节点创建新会话，核对列表及发送能力后提交，并保留原会话草稿。

macOS 右栏的「＋」打开内嵌浏览器标签。输入 HTTP(S) 地址后可前进、后退、刷新、在系统浏览器打开，以及切换自适应和 390 点移动视口。标签切换和面板隐藏保留网页状态，每个标签使用非持久化 WebKit 数据存储。「批注」允许在网页主文档中选取元素，写入当前会话草稿并随下一条消息发送。批注位置记录网页地址、元素类型和简短可见文本。

输入栏「＋」提供「添加附件」和「引用项目文件」。添加附件使用系统文件选择器，支持有序内容块的会话可以随消息发送 PNG、JPEG 和 UTF-8 文本。所选文件先显示为可移除的草稿标签。输入 `@` 或 `@目录/` 可从当前项目目录选择文件，Enter 或 Tab 将相对路径添加为可移除的引用标签。引用随消息发送。节点受理后清理本次提交的标签，结果未知时保留草稿以便核对。

在空白草稿输入 `/` 可查看当前可用的工作台命令。`/new` 打开新对话，`/status` 查看会话上下文，`/review` 使用当前审阅偏好提交工作树审查。方向键选择，Enter 或 Tab 执行，Escape 关闭建议。

`rpi-ask-user` 的多题调用逐题打开对话框。工作台按节点请求 ID 回复，每次回答后由节点推进到下一题。

左下角齿轮或 `⌘ ,`（其他平台为 `Ctrl ,`）打开「设置」。窄窗可从左侧导航打开全屏设置，再用「浏览分类」展开搜索。输入分类或控件名称可定位设置。Enter 跳到首个结果，↓ 将焦点移到结果列表，Escape 先清除查询，再关闭设置。

「外观」提供浅色、深色和跟随系统，可调整消息布局、字号、密度和代码行号。「常规」可隐藏输入栏下方的上下文入口，选择新会话的后续消息处理方式。

在「设置 → 常规 → 高级」点「编辑设置 JSON」，或在全局搜索执行 `> 编辑设置 JSON`，可用系统默认应用打开本机设置文件。首次打开会生成带默认值的可读 JSON。「复制路径」可将文件路径交给自己常用的编辑器。

- macOS `~/Library/Application Support/rpi-work/gpui-settings.json`
- Linux `$XDG_CONFIG_HOME/rpi-work/gpui-settings.json`，未设置时使用 `~/.config/rpi-work/gpui-settings.json`
- Windows `%LOCALAPPDATA%\rpi-work\gpui-settings.json`

文件采用标准 JSON。省略字段会使用默认值。`color` 可设为 `light`、`dark` 或 `system`，`theme` 可设为 `codex`、`paper`、`ocean`、`graphite` 或 `reddit`。例如以下设置使用深色海湾蓝、18 像素正文和按节点分组的项目列表。

```json
{
  "color": "dark",
  "theme": "ocean",
  "largeText": true,
  "navigation": {
    "layout": "node"
  }
}
```

编辑器保存后，已打开的工作台会自动应用有效改动。文件格式或字段值有误时，设置页会显示错误，并继续使用修改前的有效设置。界面的后续保存会保留文件里的其他字段。

「配置」显示当前节点保存的模型供应商、模型定义和凭据类型，不显示凭据内容。会话使用的模型和推理强度仍可在输入栏切换。

「代码审查」可以选择在当前会话或独立会话中呈现审查结果。此偏好保存在本机，「常规」和右栏「变更」中的选项跟随当前窗口的设置。

「通知 → 任务完成提示」默认关闭。开启后，当前会话收到实时结算时，工作台底部会显示完成、失败或停止等结果，三秒后自动消退。开关保存在本机。

工作台内按 `⌘ N` 打开当前项目的新对话草稿，`⌘ B` 切换侧栏，`⌘ Shift B` 切换浏览器面板。其他平台使用 `Ctrl`。窄窗用 Escape 关闭抽屉。「键盘快捷键」同时列出消息输入和设置搜索的键位。

侧栏放大镜或 `⌘ K`（其他平台为 `Ctrl K`）打开「搜索与操作」。可按会话或项目名称查找当前节点中的项目与未归档会话，也可查找新对话、浏览器、代码工作区和设置。查询以 `>` 开头时只显示操作。Enter 打开首个结果，↓ 聚焦结果列表，Escape 返回原草稿。

点击输入栏下方的「上下文」，或在搜索中输入 `> 查看上下文`，即可查看当前会话的项目、执行节点、模型、推理强度、消息轮次、后续消息和已报告的上下文窗口用量。节点未报告会话执行权限时，弹窗会明确标明。

「已归档的聊天」显示会话及所属项目。Tab 聚焦「恢复」，Enter 或空格可激活。节点确认恢复后，会话重新进入导航列表，设置页和当前草稿保留。从侧栏「已归档」恢复会话后会直接打开该会话。

通过「设置 → 工作协同」或全局搜索 `> 打开工作协同` 管理节点连接。

- **继续手头的工作。** 「当前窗口」显示项目和会话所属的节点。「其他工作台窗口」列出本应用已打开的节点窗口，直接切换即可回到原有会话和草稿。
- **连接另一台电脑。** 可输入 HTTP(S) 节点地址，也可从附近节点或最近连接带入地址。确认后按目标节点的要求登录。新节点在独立窗口打开，已打开且身份相同的节点会复用原窗口。附近发现可在未连接节点时主动刷新。最近连接只保存成功打开的远程节点的地址和身份，清除记录后已打开的窗口仍可继续使用。
- **让其他设备访问这台电脑。** 在本机工作区分别开启远程协作和 Web 访问。远程协作供 RPI Work 客户端连接，也会尝试发布本机供局域网发现。Web 访问提供独立的浏览器地址。仅供本机访问的网页地址会在界面标明。需要密码登录时，可在启动宿主前配置 `RPI_WORK_HTTP_PASSWORD`。远程节点的访问权限由其所属电脑管理。

macOS 可生成「地址二维码」，接收方扫码获取节点地址后按节点要求登录。本机开启远程协作后，可用「App 一次性授权」为可信设备签发最多两分钟、只能使用一次的二维码。工作台会先核对分享地址与节点身份。点击「从二维码图片连接」可选择图片，在界面核对地址并确认连接或授权。

桌面左侧快捷栏和窄窗导航中的「技能与插件」打开独立资源页。可按类型浏览当前项目的已安装技能和插件，按名称或说明搜索，并在详情中查看安装范围、版本、来源和说明。「从节点检查」读取所选资源的检查结果，「返回对话」或 Escape 恢复原会话和草稿。「设置 → 插件」和「设置 → 技能」也提供各自的目录和可展开详情。MCP 服务目录需要对应的节点接口。

### 功能入口

「设置 → 功能入口」可独立控制目标模式和工作协同快捷入口、附近节点发现、MCP 服务页签以及协同页的 Web 访问入口。快捷入口同时应用于桌面左栏和窄窗导航。开关保存在本机，工作协同页继续提供手动连接、节点共享与访问权限管理。隐藏 Web 入口只改变本机界面显示，已开启的 Web 访问可重新显示入口后在工作协同中关闭。

开启目标模式入口时，工作台读取当前执行节点的项目和全局插件目录，检查 `rpi-goal`。可复制安装命令或打开上游安装说明，安装后点击「重新检查依赖」。重新启动执行节点上的 rpi，确认扩展已加载后，可在 rpi 会话输入 `/goal status`。MCP 页签显示 `rpi-mcp-adapter` 和 `rpi-mcp-server` 的安装状态，实际服务配置和连接状态在执行节点查看。Web 入口显示 `rpi-web` 的安装状态和本机 Web 访问状态，后者来自工作协同的节点回读。工作协同行显示当前窗口的节点连接状态。

### rpi Host 管理

在「设置 → rpi Host 管理」查看此电脑上的持久化 Host area、驻留数量和 Agent 状态。macOS 上可用终端进入 area，或连接已有的可用 Agent。新 area 使用当前本机项目的目录，也可以通过系统目录选择器选定工作目录。打开页面和刷新通过 `rpi host status/list` 查询，首次进入 area 时才由 rpi 初始化并启动 Host。

macOS 和 Linux 上均可通过「选择 Host 配置」查询用 `rpi host serve` 启动的本机服务。共享 Host 入口使用 `rpi --host`，在 Linux 上提供复制命令。页面跟随 `RPI_CODING_AGENT_DIR`，默认读取 `~/.rpi/agent`。可以在「设置 → 功能入口」控制菜单显隐。

### 接入聊天软件

在运行机器人的电脑上打开「设置 → 接入聊天软件」。飞书填应用的 App ID 和 App Secret，并在飞书开放平台用长连接订阅 `im.message.receive_v1`。企业微信选择长连接智能机器人，填 Bot ID 和 Bot Secret。两个平台都可以指定允许的会话 ID，并按机器人设置自动回复。新建配置的自动回复默认关闭。飞书填写 `chat_id`，企业微信群聊填写 `chatid`，单聊填写 `userid`。

工作台将配置写入本机 `~/.rpi/agent/im.json`。密钥输入在界面中掩码显示，直接填写的密钥会写入该文件。已有配置还可以使用 `appSecretEnv` 或 `botSecretEnv` 引用环境变量。运行时按 `RPI_IM_CONFIG`、当前目录的 `.rpi/im.json`、本机用户配置的顺序查找文件。若前两项覆盖了本机配置，请在相应配置中使用该方案，或在启动时将 `RPI_IM_CONFIG` 指向本机用户配置。

扩展缺失时可复制 `rpi install rpi-im-message`，安装后刷新状态。保存后复制对应机器人的启动命令，例如 `rpi --im-message-server --im-profile feishu-main`，在运行机器人的电脑上执行。长连接由该 rpi 进程维持，可用 Ctrl+C 停止。「设置 → 功能入口」可以隐藏此菜单。 [扩展配置与平台说明](https://github.com/pi-rust/rpi-extension/tree/main/packages/rpi-im-message)

### 桌面插件

在「设置 → 插件 → 桌面插件」点击「安装示例」，即可在输入框使用 `/summarize` 整理当前会话，或用 `/test-plan` 拟定测试计划。键入 `/` 可浏览命令，点击或按 Tab、Enter 将所选模板填入草稿。编辑完成后，按正常发送流程提交。

点击「打开插件目录」，将自己的 `.json` 清单放入 `gpui-plugins`，再点「重新加载桌面插件」。打开新窗口时也会读取清单。要移除一个插件，将其清单移出目录后重新加载。已有窗口可分别重新加载。首版清单使用 `schemaVersion: 1`，每个文件声明一个插件及其 `promptTemplate` 贡献项。清单只提供文本，模板动作只替换草稿里的命令标记。本机的模板也可用于远程会话。

可复制 [示例清单](examples/workbench-starter.json) 开始编写。插件 `id` 与命令都以小写字母开头，可含小写字母、数字和连字符。插件 ID 还可含点。`command` 不含 `/`，最多 24 个字节。每份清单支持 1 至 8 个模板，每个正文最多 4,096 字节，目录最多容纳 32 份 64 KiB 以内的清单。`/new`、`/status` 和 `/review` 为内置命令。清单按文件名加载，重复 ID、命令冲突或不支持的内容会在设置中显示原因，并跳过整份清单。

### 节点技能和插件

独立资源页可通过「安装技能」或「安装插件」选择当前项目或节点全局范围。技能来源为包含 `SKILL.md` 的目录，插件来源为已构建的原生库。填写节点上的路径和资源名称后，选择「信任并安装」。节点校验来源路径并保存资源，界面回读目录核对结果。回执丢失时可刷新目录。

支持引用保护的节点会在已安装技能和插件的详情中显示「更新」「重装」和「卸载」。更新和重装需要再次确认节点来源，卸载需要确认资源名称与范围。节点拒绝改动仍被项目配置或会话选择引用的资源，包括归档会话和其他项目引用的全局资源。回执丢失时，工作台通过刷新目录核对是否已观察到变化。

独立资源页的「项目资源配置」为该项目的新会话保存主包、技能和插件选择。首次配置需选择已安装的主包，可在配置页安装节点上的包目录。保存使用节点版本校验，结果待核对时可重新读取节点配置。

技能详情在节点目录提供明确的 `SKILL.md` 路径时显示「用于新对话」。点击后打开当前项目的新对话草稿，预填一段可编辑的技能文件读取指引，并保留草稿正文、附件和审阅反馈。再次选择技能时，只替换尚未修改的预填段落。发送仍由用户确认。

「设置 → 配置」可新增、编辑和移除供应商定义，也可管理定义中的模型、推理标记和 Token 限制。节点保留未修改的高级字段，无法映射到表单的定义可在节点端编辑。目录中的供应商支持添加或替换 API 密钥，并分别清除单独保存的凭据或定义内的凭据。密钥输入会掩码显示。保存后从节点回读，配置由新宿主读取。结果待核对时可刷新目录。原始定义仍吻合时，可恢复上次编辑。

## 构建与平台

GPUI 0.2.2 与旧 Dioxus 的 `cocoa` 版本要求冲突，本应用使用独立 Cargo workspace。macOS 通过 `runtime_shaders` 在运行时编译着色器，可使用 Command Line Tools。Linux 在 Ubuntu 24.04 上构建，运行时需要支持 Vulkan 的图形驱动。Windows release 使用 Windows SDK 的 `fxc.exe` 编译着色器。各平台和架构的下载入口见 [GitHub 桌面编译](../../docs/guides/ci-builds.md)。

```bash
cargo fmt --manifest-path apps/work-gpui/Cargo.toml -- --check
cargo test --manifest-path apps/work-gpui/Cargo.toml
cargo clippy --manifest-path apps/work-gpui/Cargo.toml --all-targets -- -D warnings
```

在 macOS 上可生成带应用图标的 Finder 应用包。脚本读取可执行文件的最低系统版本，并为应用包添加本地临时签名。

```bash
cargo build --manifest-path apps/work-gpui/Cargo.toml --release --locked
bash apps/work-gpui/bundle-macos.sh apps/work-gpui/target/release/work-gpui 'dist/RPI Work.app'
open 'dist/RPI Work.app'
```
