## RPI Work 原生桌面版

- 全新的 GPUI 工作台，支持本机 rpi 工作区和远程节点连接。
- 会话区支持实时消息、工具详情和 Markdown。输入框下方直接显示 Token 用量、缓存读写和最近一轮耗时。
- 项目面板支持浏览文件、查看 Git Diff 和提交审阅反馈。

## 下载安装

- macOS 下载对应架构的 ZIP，解压后打开 `RPI Work.app`。应用使用临时签名。
- Linux 下载对应架构的 tar.gz，解压后运行 `work-gpui`。构建基于 Ubuntu 24.04，运行需要支持 Vulkan 的图形驱动。
- Windows 下载对应架构的 ZIP，解压后运行 `work-gpui.exe`。

这是首个 GPUI 桌面 Release。旧版客户端请下载对应平台的桌面包并手动安装。本次发布覆盖 macOS、Linux 和 Windows。旧版 Android 和 Web 包仍可从 `v0.1.22` 下载。
