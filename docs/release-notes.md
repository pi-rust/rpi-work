RPI Work 0.1.21

## 工作协同：当前节点优先

- 工作协同页默认突出当前节点：桌面先显示本机节点身份、本机 RPC 与可分享地址，再列出已连接节点；其他节点可直接“设置”或“切换”，切换只改变本设备使用哪个节点。
- 手机端只显示正在连接的远程节点，提供分享、一次性授权和断开；连接其他节点支持扫码、地址输入与附近节点刷新，不显示入站权限和历史。
- “允许远程协作”和“允许 Web 访问”收进当前节点；切到远程节点后改为说明权限在拥有该节点的电脑上管理，避免把本机权限套到远程节点。
- 节点设置弹窗显示地址、当前/未在使用状态，并可直接切换到该节点；浏览器托管且没有本机 RPC 时不再伪显示本机节点在线。
- 发现、连接、远程协助、Web 访问与一次性授权仍各自独立；地址二维码和发现记录只包含地址，不含密码或授权票据。

RPI Work 0.1.20

## 连接发现与离线恢复体验

- 工作协同支持在桌面端发现同一局域网中已开启远程协作的 Work 节点，并在连接前展示节点地址、身份、协议、健康状态和认证状态，确认后才建立连接。
- 节点通过 mDNS 发布受节点身份约束的 HTTP 发现信息；客户端仍会使用现有无凭据探测和节点身份校验，不在发现阶段传输密码或登录凭据。
- 节点无法连接时，桌面和移动工作区不再显示空白页面，首页会显示原因并提供进入工作协同设置的操作入口。
- 修复 Web 入口按钮样式和可访问性，保留独立 Web 入口、远程协作和现有连接行为。
- Android versionCode 为 1020。多平台包和签名更新清单由标签流水线构建与验证。

## 工作协同与后台运行

- 远程协作和 Web 访问提供两个独立开关，各自保存设置和撤销登录，访问同一个节点的项目、会话和任务。
- Work 网页界面随桌面包分发，Web 默认使用 13032，远程协作默认使用 13031。开发代理同步连接 Web 监听端口。
- 新增“一键后台运行”，隐藏窗口并请求 Windows WebView2 低内存模式。托盘提供恢复窗口和退出节点入口，草稿、附件及运行任务持续保留。
- 分别显示 Web 资源缺失、监听失败和状态读取错误，并提供重新检测及准备指引。当前使用 Work 自有节点和 HTTP 适配，原生 rpi --node 扩展的自动下载安装尚未接入。

## 文件预览与阅读体验

- 消息中的目录链接在文件树中打开，省略路径的文件名会在当前项目内定位。同名文件提供完整路径选择，读取错误按节点错误类型显示。
- 修复文件重试、专注阅读布局和焦点恢复，补全代码及 Diff 语法高亮，并调整思考内容样式。

## 资源安装与品牌

- 安装资源时可选择目标节点，并从该节点读取项目和资源来源。切换目标后重新选择安装范围，跨节点 Web 跳转保留经核对的公共资源引用。
- Windows、macOS、Android 安装图标及应用图标采用用户提供的品牌 logo。
- Android versionCode 为 1019。多平台包和签名更新清单由标签流水线构建与验证。

## Agent / UI 独立扩展架构

- 区分 Agent-only、UI-only 与 Agent+UI 扩展。会话按固定版本记录 Agent desired pins；UI 可见性独立保存，隐藏 UI 不改变 Agent 配置。
- UI 扩展使用受控、转义的静态 widgets；资源库、设计稿、导入导出和恢复流程保留完整声明与版本快照。
- Agent 运行、等待交互或状态未确认时，以 fail-closed 方式锁定 Agent 配置；UI 偏好仍可独立操作。
- 提供基于真实原生插件、rpi RPC 工具事件和受控实时 Dioxus 页面的开发 Demo，包含计数、取消、清理及失败路径验证。

**能力边界：**正式客户端尚未接入通用扩展安装/加载及会话 applied 协议；导入、选择、预览只表示本地设计和 desired 状态，不表示扩展已在节点安装或执行。实时 Demo 适配器仅供开发验证，不是正式通用 live UI 协议。完整视觉参数目前通过 JSON 编辑，界面提供规格摘要，尚无逐字段可视化编辑器。
