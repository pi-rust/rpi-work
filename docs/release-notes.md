RPI Work 0.1.8

## Codex 默认主题与完整视觉规格

- 默认主题改为 Codex 黑白：浅色白色画布、低饱和灰色分区，深色石墨灰表面；已有有效主题偏好不强制覆盖，原四套主题继续保留。
- 打磨消息排版、导航和标题层级、圆角输入区、轻阴影及圆形发送按钮。窄屏会话标题正确省略，资源工具栏可横向滚动，运行/错误与节点状态继续可见。
- 新增完整主题 JSON v2：可分别配置正文、标题、代码字体，以及字号倍率、角色字号、行高、字重、间距、圆角、控件/触控尺寸、边框、阴影和动效。兼容 v1 主题及已有偏好，支持实时预览、取消恢复、保存和无损导出。
- 主题只接受本机安全字体栈和有界数值，不加载远程字体或任意 CSS；保留手机输入字号、主要触控目标和系统减少动效的安全规则。

## Agent / UI 独立扩展架构

- 区分 Agent-only、UI-only 与 Agent+UI 扩展。会话按固定版本记录 Agent desired pins；UI 可见性独立保存，隐藏 UI 不改变 Agent 配置。
- UI 扩展使用受控、转义的静态 widgets；资源库、设计稿、导入导出和恢复流程保留完整声明与版本快照。
- Agent 运行、等待交互或状态未确认时，以 fail-closed 方式锁定 Agent 配置；UI 偏好仍可独立操作。
- 提供基于真实原生插件、rpi RPC 工具事件和受控实时 Dioxus 页面的开发 Demo，包含计数、取消、清理及失败路径验证。

**能力边界：**正式客户端尚未接入通用扩展安装/加载及会话 applied 协议；导入、选择、预览只表示本地设计和 desired 状态，不表示扩展已在节点安装或执行。实时 Demo 适配器仅供开发验证，不是正式通用 live UI 协议。完整视觉参数目前通过 JSON 编辑，界面提供规格摘要，尚无逐字段可视化编辑器。

## 验证与安装

- 修复 Web 发布工作流中的旧脚本路径，增加工作流脚本存在性检查；v0.1.7 因构建入口失败未公开，正式版本顺延，未覆盖原标签。

- 本地 workspace：193 项测试通过、0 失败，4 项既有 ignored；格式与严格 Clippy 检查通过。
- 正式 WASM 与模块构建、主题/设置/更新/扩展/资源库七套浏览器回归通过，覆盖浅深色、持久化、取消恢复、390/320px 和触控边界；开发 Demo 的真实宿主及正负向验证另行完成。
- 本地验证不等于所有平台的实机验证；各平台发行制品由标签 CI 构建、校验并发布签名更新清单，不调用外部模型。

Android ARM64 APK 沿用固定签名，versionCode 1008，可从此前固定签名版本覆盖升级。执行宿主仍由电脑节点提供；节点密码、模型密钥和本机配置不包含在安装包中。桌面包仍为便携发行，未增加 Windows MSI、Apple 签名/公证或应用商店发行支持。
