RPI Work 0.1.6

- 手机“连接我的电脑”新增可展开的“手动输入地址”，支持 HTTP(S) 域名、局域网 IP 与端口；保留相机和相册扫码。
- 手动连接沿用节点校验、密码登录和项目/会话加载流程，支持回车提交；仅编辑地址不会切换正在使用的节点。
- 展开手动输入时关闭相机并取消未完成的图片识别，避免迟到的识别结果覆盖草稿；收起再展开保留输入。
- 拒绝手机回环地址、携带账号密码的地址和非 HTTP(S) 协议；无效输入不影响当前工作空间。

Android ARM64 APK沿用固定签名，versionCode 1006，可从此前固定签名版本覆盖升级。执行宿主仍由电脑节点提供，节点密码与模型密钥不会包含在安装包中。
