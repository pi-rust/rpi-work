# 节点连接交互（0.1.2）

手机入口为“连接我的电脑”，仅提供相机扫码与相册扫码。识别二维码后展示目标地址，用户确认后连接；节点需要认证时再显示密码登录。手机不展示服务端角色、生成二维码、粘贴连接信息或高级地址表单。

电脑设置保留“执行节点”：默认使用本机节点，可重连本机、连接其他节点，或通过“手机连接这台电脑”展示地址二维码。当前节点的在线、认证和能力信息均来自实际请求；界面不会将客户端所在电脑直接标成已启动或已在线。

Android始终使用手机模式；原生桌面始终使用电脑模式。Web结合移动设备标识与窄屏断点选择入口，手机横屏仍保持手机模式；从窄屏恢复到桌面布局会关闭相机并释放轨道。

二维码仍使用现有版本化地址协议，不包含密码；回环、通配地址、凭据与未知协议版本仍被拒绝。原生BarcodeDetector不可用时，以随应用分发的jsQR本地解码；相册识别不上传图片。

正式WASM复验：构建后运行 `node scripts/verify-device-flow.cjs`，覆盖桌面连接、分享二维码、手机识别后确认、真实二维码图片解码、延迟相机权限关闭和移动布局。相机权限使用测试流，不能代替真机摄像头验证。旧手机连接设计稿和原型截图属于历史设计，以本说明为准。
