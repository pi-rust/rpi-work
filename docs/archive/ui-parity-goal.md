# RPI Work 1:1 还原目标

2026-10-25，用户要求：检查当前实现的问题，让 rpi 编写代码，Codex 审查，实现已确认 HTML 原型的 1:1 还原。

## 基准和完成定义

- `design/prototype/index.html` 与其加载的 CSS/JS 是视觉、信息架构和交互基准。不得改原型来迎合实现。
- 正式实现仍是 Rust / Dioxus；保留 work-client、work-core 的真实 HTTP/SSE 数据链路。不得 iframe 原型、用原型 JS 替代 Dioxus，也不得伪造真实业务成功。
- 对照所有导航、对话、工具、计划、ask、BTW、队列、配置、用量、附件、文件、变更、主题、项目、追踪、资源库、元Agent、设置、节点连接页面。
- 上游支持的能力接真实协议；缺少协议的能力也须保留完整可用 UI、清晰的未连接/不可用说明和恢复入口，单独记录服务端缺口。只做禁用按钮不算完成。真实行为与原型样例的数据差异应明确排除，不能以此排除布局和交互。
- 在相同主题、密度、视口、状态下检查 1440×1000、1280×800、768×1024、390×844、320×740；主对话标题+工具栏桌面 96px（不含演示条），移动端同样 96px；不得横向溢出。
- 截图应覆盖正式 Dioxus 渲染而非静态原型；需要可重复的前端状态 fixture，但 fixture 必须显式测试专用。
- 必须验证空态、错误、加载、流式、中断、会话/项目快速切换、模态框 Escape/焦点、移动抽屉/底栏、主题切换；保持草稿与滚动，防止异步旧请求污染新会话。
- Rust fmt/test/clippy + 实际 WebView/浏览器交互和截图审查通过；最后逐项报告通过、未通过和后端协议缺口。目标仅在必要项全部完成后完成。

## 初审问题

1. **P0：CSS 作用域错误。** `apps/work-ui/src/app/workspace.rs` 原始第150行打开 max-width:760px 媒体查询却未关闭，新版布局和另一个嵌套媒体查询均被包住。桌面仍用旧版三列（侧栏+旧会话列表+对话+Inspector），移动侧栏也被旧 display:none 隐藏。
2. **P1：旧会话面板与新侧栏重复。** 工作区保留旧创建/搜索/文件列表；顶部/输入/Inspector 多处重复信息，偏离紧凑对话。
3. **P1：节点和 Provider 配置位置错误。** 连接地址/节点卡片在侧栏，缺少正式设置入口和页面。
4. **P1：视觉系统丢失。** 硬编码单主题、文本字符模拟图标、无主题选择，原型四主题/深浅/密度均未迁移。
5. **P1：会话配置缺失。** Skills/Tools/提示词/具名 Package 的会话顶部入口缺失，Packages/Skills/扩展只剩禁用导航。
6. **P1：composer 功能缺失。** 模型/模式/附件等控件禁用；用量/缓存/context footer 缺失；Enter 处理需检查 IME 和默认换行。
7. **P1：项目表单落后。** 已有目录/新建目录、目录浏览、自定义别名和元Agent类型与最新原型不一致。
8. **P1：会话追踪、BTW、元Agent、预览、资源生命周期等未迁移。** 需要逐页面核查，不能以 Cargo 编译通过宣称还原。
9. **验证缺口：** 现有 work-ui 无 UI 测试；21个 Rust 测试主要覆盖 transport/reducer/node，无法发现上述布局错误。

## 工作分工

- rpi：分批实现、提交可审查源码改动与每批验证记录（未经用户要求不 git commit/push）。
- Codex：冻结原型基准、维护差距清单、独立审查代码和真实渲染、把失败项退回 rpi；必要时修正验收工具。
- 不删除任何现有未提交改动，不读写用户凭据，不修改相邻仓库；不启动额外子代理。

1. 修复基础布局作用域，移除重复旧面板，拆分 CSS；还原桌面/移动导航、紧凑顶部、设置/节点入口、四主题和模态框基础。
2. 项目/会话/文件/变更、composer/配置/footer、流式工具与对话的交互还原。
3. 资源库、追踪、元Agent、连接以及剩余原型页面，按真实协议能力细分实现与缺口。
4. 多视口视觉和行为回归、异步状态审查、文档真实性核对，直到完成定义全部满足。
