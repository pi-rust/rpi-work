## 当前基准与入口

`design/reui-message-layout/` 是已确认的视觉与交互基准。`apps/work-gpui/` 是当前唯一维护的 UI。`task desktop` 启动原生 GPUI 窗口，`--connect` 使用共享 Rust 客户端读取真实节点。当前已接入整窗外壳、项目和会话列表、实时会话转写、纯文本发送、会话重连、发送回执核对、原生输入法与文本选区、模型与思考等级的会话目录及写后读回、可展开工具、主题切换、窗口内草稿、停止、单选审批、单个问题的多选和文本回答、历史和流式 Markdown 正文、原生项目概览、项目目录和源码读取、同栏 Git 文件列表与双行号差异、会话前进后退、节点现有目录注册与列表核对、节点新建会话与读回、可调整宽度的桌面右栏和窄窗抽屉。macOS 右栏已接入同窗 WebKit 浏览器、多标签、HTTP(S) 导航和移动视口。同栏文本差异支持核对补丁后的逐行反馈，随当前会话草稿提交。运行工作树审阅会复读真实 Git 状态，支持在当前会话或独立会话发起请求。macOS 浏览器支持页面元素批注。节点协同及正式打包仍待接入。

`apps/work-ui` 和 `apps/workbench-ui` 已废弃。下面是 React 迁移阶段的历史记录，可用于核对共享 Rust 契约和验收用例。表中的完成状态指当时的 React 实现。

## 已有真实链路

- `src/lib/node.ts` → `work-client-wasm` → `WorkspaceClient` / typed NodeApi；保留协议、认证与 endpoint 的 Rust 所有权。
- `src/lib/workspace.ts` 接项目、会话、历史、实时投影、发送、中止、队列、配置、源码、资源及供应商；需逐项复核能力观察、scope/generation/epoch、ACK 与 settlement，不直接把旧代码存在当成完成证明。
- `src/lib/viewmodel.ts` → `work-viewmodel-wasm` / RunProjection；不在 TypeScript 另造消息行序、工具摘要或执行状态机。
- `src/lib/theme.ts` 消费 Rust 主题 contract；展示偏好不得改变 Agent 配置和权限。

- 生产与夹具构建、17 套浏览器回归、会话专项 29 项、真实节点托管 17 项和 560 项 Rust 测试通过。托管使用合成原生进程验证 `resumed: false` 后下一条提示仍能受理，以及成功恢复后回读队列。会话专项覆盖受理等待、明确拒绝、断连、跨会话、320px 触控以及草稿选区和真实 iframe 保留。原生库和 WASM 严格 Clippy 通过，原生测试目标的额外检查仍报 6 处既有空值断言警告。前端 lint 68 条既有警告、0 错误。日志位于 `/tmp/rpi-queue-resume.1lv53B/`。

- 独立资源页和设置中的可展开详情共用「从节点检查」，按当前项目和资源引用通过 `WorkspaceClient` 提交只读 `NativeManagement::Inspect`。原生验收覆盖 HTTP 503 后手动重试、重复激活和迟到结果隔离。独立页验收覆盖桌面 IME 搜索、无匹配状态、类型切换、列表选择、MCP 状态、680 × 480 点窗口检查按钮随焦点滚动，以及返回对话后恢复原草稿。目录首次返回 HTTP 503 后可手动刷新，重新打开设置时保留原设置页。请求断言覆盖资源引用和安装范围，资源写入、会话创建、提示发送和模型调用均为零。
- 「用于新对话」根据所选已安装技能的节点目录记录生成可编辑的 `SKILL.md` 读取指引，并打开当前项目的新对话草稿。切换技能时更新未经编辑的预填段落，原有正文、附件和审阅反馈保留。原生验收使用真实节点和实际安装的技能，覆盖桌面搜索、项目与全局同名技能选择、680 × 480 点窗口键盘激活、切换技能后保留草稿正文，以及已有会话草稿恢复。预填期间资源写入、会话创建、提示发送和模型调用均为零。发送后能否读取该文件取决于运行时的文件权限。

## GPUI 代码审查设置

- 「代码审查 → 结果」和「常规 → 工作区」共用审查结果选项。设置搜索直接定位「代码审查」中的选择控件。右栏发起审查时读取同一项设备偏好。
- macOS 原生验收覆盖按字段搜索、Tab 和空格选择独立会话、680 × 480 点常规页同步显示、恢复草稿，以及重启后从分类搜索验证已保存选项。验收期间的会话创建、提示发送和模型调用为零。
- 设置导航按原型分为应用、数据与隐私、集成和编码。macOS 原生验收覆盖桌面分组及 680 × 480 点窗口中的 Tab、Shift+Tab、焦点跟随滚动和空格打开代码审查。Escape 关闭设置后继续编辑原草稿。

## GPUI 节点模型供应商

- 「设置 → 配置」通过 `WorkspaceClient::provider_catalog` 读取当前节点保存的供应商、模型定义和凭据类型。界面按节点报告区分配置文件中的定义和凭据来源。新会话默认模型、默认推理强度和执行权限仍需对应的节点契约。
- macOS 原生验收覆盖设置搜索、HTTP 503 后键盘刷新、680 × 480 点窗口、仅凭据条目、旧版定义和草稿保留。供应商目录请求均为 GET。隔离节点的配置与凭据文件未改变，未创建会话、发送提示或调用模型。
