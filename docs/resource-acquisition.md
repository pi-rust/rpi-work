# 扩展、Skills 与 Package 的下载前置

三种资源统一采用：`目录可浏览 → 下载到执行节点 → 安装到节点 → 明确启用 → 读取或调用`。未下载不能安装，未安装不能启用；下载和安装都不能自动修改会话能力。卡片同时展示当前状态与三步进度。

扩展在执行节点启用，开关在未下载、未安装或当前回合未结束时不可操作。Skills 在安装后由会话明确启用，再指定给某条消息。Package 安装后绑定到会话，包内 Skills 继承该包的下载、安装和版本绑定状态，不重复单独下载。

初始已启用资源是预先下载并安装的演示数据。技能目录新增未下载的 `api-contract-review`，可以完整体验下载、安装、启用、指定和停用；已有技能的解析失败、来源覆盖与使用记录仍单独显示。

「下载到执行节点」和「导出 JSON」分开：前者改变目标节点获取状态，后者只保存可分享的设计包。手机保存文件、浏览目录、查看 Skill 正文或导入 JSON，都不会让执行节点自动获得资源，也不会自动授权或启用资源。

当前下载过程、节点安装和启用都是本地状态模拟，没有下载远程代码或安装原生扩展。真正的执行节点仍需要获取字节、验证资源、原子安装及报告结果；原型中导出的 JSON 设计包不包含可执行插件。停止使用不删除历史事件，未发送的失效技能引用会从草稿中移除；历史会话与运行快照保持不变。

`verify-resource-lifecycle.cjs` 覆盖扩展开关前置、独立 Skill 三步启用与会话隔离、Package 及内含 Skill 的继承、导出不等于节点下载、异步获取不覆盖其他弹窗，以及 320–1440px 布局。结果：[resource-lifecycle-validation.json](../artifacts/resource-lifecycle-validation.json)。
